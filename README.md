# ByggPlan Web

React- och Vite-frontenden för ByggPlan.

## Cloudflare Pages

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

Appen använder som standard API:t på `https://api.byggplan.tunell.org`.

För en annan miljö kan variabeln `VITE_API_BASE_URL` anges i Cloudflare Pages.
